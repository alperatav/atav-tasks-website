# Atav Tasks Website

Official static product website for Atav Tasks.

## Development

Open `index.html` directly or serve the directory with any static web server.

## Privacy

The site has no backend, analytics, advertising trackers, cookies, API keys, or account system. Product screenshots are real Android MVP screens; visible personal account information is masked before publication.

## Deployment

Designed for GitHub Pages from the `main` branch root.
